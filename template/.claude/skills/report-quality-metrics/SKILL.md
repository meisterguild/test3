# /report-quality-metrics コマンド

プロジェクトの品質指標を報告するコマンドです。

## 使い方

| 呼び出し | 動作 |
|---|---|
| `/report-quality-metrics` | 品質指標を測定してレポートを出力する（デフォルト） |
| `/report-quality-metrics --setup` | 各指標の測定に必要なツールを導入する |

引数に `--setup` が含まれる場合は **セットアップモード**、含まれない場合は **レポートモード** として動作します。

## 担保する品質指標

導入されるリンタ―は docs/quality/metrics.md に記載されている品質指標になります。
CI組込、リンター組込、CD組込のいずれかで指標を測定し、レポートすることが求められます。

## --setup モード（測定ツールの導入）

引数に `--setup` が指定された場合、各品質指標の測定に必要なツールを導入します。
プロジェクトの言語やフレームワークに応じたものを導入します。
既にインストール済みの場合は何もしません。

## レポートモード（デフォルト）

`--setup` が無い場合は、導入済みのツールを使って各指標を測定しレポートします。
ツールが未導入の場合は、先に `--setup` を実行するようユーザーに案内してください。

### レポートのフォーマット

レポートは以下のフォーマットで出力されるものとします。

```
| 指標名 | 値 | コメント |
|---|---|---|
| コードカバレッジ | 85% | 目標は90%以上 |
| コード品質スコア | 7.5/10 | 目標は8以上 |
...
```
