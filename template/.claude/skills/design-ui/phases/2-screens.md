# 工程② 画面整理

> `/design-ui` の工程②。ここには詳細手順のみを記載する。順序・CP・共通前提は `../SKILL.md` を参照。

1. 画面一覧と各画面定義を `../templates/screen-definition-template.md` に従って作成する。
   - **網羅性を担保する**：要件にある画面・機能を漏れなく挙げ、各画面の「状態」も状態カテゴリ（①展開 ②取得中・エラー ③空・任意未入力 ④通知・トースト・バナー ⑤OS 委譲は画面化しない）で洗い出す（`../rules/wireframe.md`「網羅性」参照）。要件に明記が無くても UX 上必要な状態は仮置き事項として挙げる。
   - 過去案件の参考デザインがある場合は、**網羅チェックの照合材料**として使う（コピーしない。古い・対象外の画面を含むことがあるため要件を軸に取捨する）。
2. `docs/internal/design/02-screen-definition.md` に出力する。
3. 簡易的なユーザーフロー（画面遷移）も添える。
