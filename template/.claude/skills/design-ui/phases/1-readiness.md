# 工程① 着手チェック（Design Readiness Check）

> `/design-ui` の工程①。ここには詳細手順のみを記載する。順序・CP・共通前提は `../SKILL.md` を参照。

1. `../rules/design-readiness-check.md` の観点で、要件定義書と機能仕様を確認する。
2. 不足・未確定・確認事項を `docs/internal/design/01-readiness-check.md` に出力する。
   - 確認事項は **Critical / Warning / Review / Assumption / Deferred / Out of Scope** に分類し、**Critical 0 件＋観点を変えて最大 2 回**で終了する（詳細は `../rules/design-readiness-check.md`）。
3. 判定（Go / Conditional Go / Stop）を提示する。

→ **★CP1：人間 / PM 確認**
