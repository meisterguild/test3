# Product Overview

## プロダクト概要

ブラウザ上で遊べる「スイカゲーム」型の落ち物パズルゲーム。同じ種類の果物を接触させて合体させ、より大きな果物へ育てながらハイスコアを狙う。サーバーを持たない**静的 Web アプリ**（HTML + JS）として配信し、URL を開くだけで遊べる状態を目指す。

## ターゲットユーザー

- スマートフォン / PC のブラウザで、インストールなしに短時間（1 プレイ 1〜3 分）遊びたいカジュアルゲーマー
- 開発チーム自身（本テンプレートの AI 開発フローを実プロジェクトで検証するための題材）

## MVP機能

- 果物の落下操作（左右移動 → ドロップ）
- 物理シミュレーションによる積み上がり・衝突
- 同種果物の合体（11 段階の進化チェーン）
- スコア計算・表示、ハイスコアのローカル保存
- ゲームオーバー判定（デッドライン超過）とリスタート
- 次に落ちる果物のプレビュー
- スマートフォン縦持ち / PC 双方で遊べるレスポンシブ表示

## 非MVP

- オンラインランキング / サーバー側のスコア保存
- マルチプレイヤー・対戦モード
- アカウント登録・ログイン
- リプレイ保存・共有機能
- 課金要素・広告
- ネイティブアプリ（iOS / Android）配信
