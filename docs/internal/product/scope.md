# Project Scope

## MVP Scope

「URL を開けば最後まで 1 ゲーム遊べる」ことを MVP の完成条件とする。具体的には次の 1 周が成立すること。

1. ゲーム画面が表示され、次の果物が確認できる
2. 左右に狙いを付けて果物を落とせる
3. 落ちた果物が物理挙動で積み上がる
4. 同種果物が接触すると 1 段階上の果物へ合体し、スコアが加算される
5. デッドラインを一定時間超えるとゲームオーバーになり、スコアとハイスコアが表示される
6. リトライすると 1 に戻る

付随して MVP に含めるもの。

- ハイスコアの `localStorage` 永続化
- スマートフォン縦持ち（タッチ操作）と PC（マウス / キーボード）の両対応
- 効果音とミュート切替（優先度は低。無くてもゲームは成立するが MVP スコープには含める）
- 単体テスト（Vitest）と E2E テスト（Playwright）の最小セット
- GitHub Pages への静的デプロイ

## Excluded

以下は MVP から明示的に除外する（[product.md](./product.md) の「非MVP」と同じ）。

- オンラインランキング / サーバー側スコア保存（バックエンドを持たない方針のため）
- マルチプレイヤー・対戦モード
- アカウント登録・ログイン
- リプレイ保存・共有、SNS 連携
- 課金要素・広告
- ネイティブアプリ配信
- 果物以外のテーマ / スキン切替
- 実績・デイリーミッション等のメタ進行

## Future

MVP 後に検討する候補（本計画では issue 化しない）。

- スコアのシェア用画像生成（Canvas から PNG 書き出し）
- 難易度モード（容器サイズ・出現果物テーブルの切替）
- オンラインランキング（サーバー導入の是非を含めて再検討）
- アニメーション演出の強化（合体エフェクト・パーティクル）
- PWA 化（オフライン起動・ホーム画面追加）
